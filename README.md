# Roadwork

Roadwork is a work-plans system by 2nd Cortex Labs: a folder of plans — todos, features, sparks — and the skills that work them, from a thought to a recorded, verified change. This repository is what every project's work-plans folder is cloned from: the folder's skeleton with its anchors, its documents, the register rule, the lifecycle skills and unlazy.

To use it: clone this repository as your project's work-plans folder, at the path your project's law names, and run the setup, which installs the skills and the rule into your project's skills folder. Then read `docs/teachme.md` first; `docs/terms.md` gives the plain word for every term the skills use.

Nothing here is specific to any one project: no keys, no names, no items. Your items, your maps and your records are yours; they never come from here.
